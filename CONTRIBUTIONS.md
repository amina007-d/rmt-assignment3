## Commit order (one shared branch)

Pull before each commit (`git pull --rebase`), so the history stays linear.

1. **Amina:** `README.md`, `requirements.txt`, `.gitignore`. Message: "Add project setup: README, pinned requirements, gitignore".
2. **Nazerke:** `src/resources.py`. Message: "Add entity taxonomy, name/place/org pools and gazetteers".
3. **Nazerke:** `src/generate_prompts.py`. Message: "Add synthetic prompt generator with valid IIN/IBAN and gold spans".
4. **Amina:** `src/detectors.py`. Message: "Add rule-based, NER-based and hybrid detectors".
5. **Amina:** `tests/test_detectors.py`. Message: "Add unit tests for checksums and detectors".
6. **Nazerke:** `src/evaluate.py`. Message: "Add evaluation: overlap/strict metrics, latency, bootstrap CIs, H1-H2 tests".
7. **Amina:** `data/prompts.jsonl`, `results/`, updated `README.md` (generated by running the README commands; no hand-written files). Message: "Add pilot dataset (seed 42) and evaluation results".
8. **Nazerke:** `src/seed_robustness.py`, `results/seeds/`, `results/seed_robustness*.csv`. Message: "Add seed robustness check (seeds 1-5)".
9. **Amina:** `src/plots.py`, `figures/`. Message: "Add figures for the report".
10. **Nazerke:** `CONTRIBUTIONS.md`. Message: "Add contribution split and commit plan".

Example for one step:
```
git add src/detectors.py
git commit -m "Add rule-based, NER-based and hybrid detectors"
git push
```
Before step 7, run the README commands and check that `results/run_log.txt` matches Table 3 of the report.
